Esta pasta é **só o que fica público**: as páginas de propostas que o `.bat` publica no modo sem crédito (GitHub Pages, gratuito).

- O trabalho de verdade (cotações, planilhas, chaves de API, rascunhos) fica em `D:\02_PROJETOS_CLAUDE`, **fora** deste repositório.
- Aqui entram só os arquivos finais já prontos para o cliente ver: `propostas/<cliente>-<destino>/<opção>.html`.
- Nunca commitar PDF de cotação, planilha de cliente ou qualquer coisa com "chave", "token" ou "senha" no nome.
